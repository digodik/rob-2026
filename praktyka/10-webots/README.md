## ⚠️ Єдина установка за семестр

[Webots](https://cyberbotics.com) — безкоштовний, ліцензія Apache 2.0,
без реєстрації й без обмежень. Ставиться **один раз, сьогодні**.

Перші дев'ять тижнів ви працювали в браузері. Це було навмисно:
щоб курс починався з робота, а не з установки.

## Умова

1. Встановити Webots.
2. Відкрити готову сцену з роботом **e-puck**.
3. Запустити контролер на Python — той самий рух за лінією,
   що ви робили в Gears.
4. **Змінити один параметр** і подивитись, що станеться.
5. Записати, що саме змінилось.

Файли: `kontroler.py`, `zvit.md`, скріншот.

## Контролер Webots — мінімальний каркас

```python
from controller import Robot

TIMESTEP = 32
robot = Robot()

left  = robot.getDevice('left wheel motor')
right = robot.getDevice('right wheel motor')

# нескінченна позиція = керуємо швидкістю, а не кутом
left.setPosition(float('inf'))
right.setPosition(float('inf'))
left.setVelocity(0.0)
right.setVelocity(0.0)

gs = []
for name in ['gs0', 'gs1', 'gs2']:
    s = robot.getDevice(name)
    s.enable(TIMESTEP)
    gs.append(s)

while robot.step(TIMESTEP) != -1:
    values = [s.getValue() for s in gs]
    # ваша логіка тут
    left.setVelocity(3.0)
    right.setVelocity(3.0)
```

⭐ Три речі, яких не було в Gears:

| Що | Навіщо |
|---|---|
| `robot.step(TIMESTEP)` | симуляція крокує явно; без цього нічого не рухається |
| `setPosition(float('inf'))` | перемикає мотор у режим керування швидкістю |
| `s.enable(TIMESTEP)` | датчик треба **увімкнути**, інакше він мовчить |

## Три рівні

**Ядро (всі).** Webots встановлено, сцена запускається, один параметр
змінено, наслідок описано.

**Трек Д.** Змінити сцену **візуально**: освітлення, кольори підлоги,
текстури. Потім прогнати робота ще раз.

⭐ Це не декорація: у Webots освітлення реально впливає на покази
датчиків, бо вони моделюються фізично. Зафіксуйте числами, як
зміна освітлення змінила покази — це технічний результат, отриманий
візуальним інструментом.

**Трек П.** Перенести **свій** регулятор із Gears: той самий `Kp`,
та сама логіка. Порівняти поведінку. Числа не збіжаться — поясніть,
чому.

## ⭐ Із зірочкою

Знайти, чим **e-puck принципово відрізняється** від робота в Gears:
кількість і розташування датчиків, діапазон значень, розміри, база
коліс.

Виписати три відмінності, які змушують міняти код, а не тільки числа.

---

## ⚠️ Якщо Webots не став

Буває: стара відеокарта, корпоративний ноутбук, немає прав.

Скажіть **на парі**, не через тиждень. Варіанти є:
- працювати в парі з одногрупником на його машині;
- лишитись у Gears і довести місію там — це **повністю прийнятний**
  шлях, курсова від цього не стає гіршою;
- дочекатись доступу до хмарної версії, якщо він з'явиться.

⭐ Webots — інструмент поглиблення, а не умова заліку. Ваша місія
з картки виконується в будь-якому з двох середовищ.
