# Робота 6. Поведінка як автомат станів

Тиждень 6 · до **5 балів** за роботу + ⭐ **15 балів** за відео місії

---

## Умова

Розкласти **свою місію** на стани й реалізувати три-чотири з них.

1. Виписати, що робот має вміти робити: шукати, їхати, обʼїжджати,
   зупинятись, повертатись.
2. Намалювати **діаграму станів**: прямокутники — стани, стрілки —
   переходи, на стрілках — умови.
3. Реалізувати 3–4 стани в коді.
4. Запустити. Записати відео 30 секунд.

Файли: `dijagrama.png` (можна фото від руки), `misiya.py`,
`video.mp4` або посилання, `zvit.md`.

---

## Скелет, від якого можна відштовхнутись

```python
stan = "poshuk"

while True:
    if stan == "poshuk":
        # їдемо вперед, дивимось на датчик
        if znaydeno():
            stan = "pidhid"

    elif stan == "pidhid":
        # наближаємось
        if blyzko():
            stan = "diya"

    elif stan == "diya":
        # робимо те, заради чого приїхали
        stan = "povernennya"

    elif stan == "povernennya":
        # їдемо назад
        if na_bazi():
            break
```

⭐ Зверніть увагу: **у кожен момент робот перебуває рівно в одному
стані**, і в коді немає жодного вкладеного `if` глибше двох рівнів.
У цьому вся ідея.

---

## ⭐ Головне сьогодні

«Одна велика функція з `if`» ламається на четвертій умові. Не тому,
що ви погано пишете — тому, що умови починають перетинатись,
і ви більше не можете сказати, у якому стані робот зараз.

Автомат станів прибирає саме це: **завжди зрозуміло, де ви є
й куди можете піти далі.**

---

## Три рівні

**Ядро (всі).** Діаграма намальована, 3–4 стани працюють,
відео знято.

**Трек Д.** Діаграма має бути зрозуміла **людині без технічної
освіти**: назви станів словами, а не `stan_2`; підписані переходи.
Плюс подумайте, як робот **показує назовні**, у якому він стані —
рух, пауза, розворот. Це поведінка як комунікація.

**Трек П.** Додати **стан обробки відмови**: робот застряг —
відʼїхати назад, повернути, спробувати ще раз. Порахувати
на десяти прогонах, скільки разів цей стан спрацював.

---

## ⭐ Із зірочкою

Знайти в своїй діаграмі стан, **у який робот може потрапити,
але з якого не може вийти** — глухий кут автомата.

Він майже завжди є в першій версії. Опишіть його й додайте вихід.

⚠️ Це рівно те, що на захисті питають першим із технічних питань:
«який стан спрацьовує, коли робот застряг?»
